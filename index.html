wiw-content-machine

wiw-content-machine is a private tool used by one person, its owner (thanakrit.naeo@gmail.com). It renders the owner's own explainer videos and copies the finished files into the owner's own Google Drive.

Privacy policy

  • Google data used: Google Drive with the drive.file scope only. The tool can see and change only the files and folders it created itself. It cannot read any other file in the Drive.
  • What it does with it: creates folders and uploads the owner's video, audio, image and text files, and downloads those same files back when a job is resumed. It never deletes files.
  • Sharing: no data is sold, shared with third parties or used for advertising. Nothing is collected from anyone other than the owner.
  • Storage of credentials: the refresh token is kept as an encrypted credential in the owner's own cloud environment and is never written into code or files.
  • Revoking access: the owner can remove access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
